# Career Atlas Web — เวอร์ชันสำหรับนักเรียน (ไม่ต้อง Login)

เว็บไซต์ Static ที่สร้างจากวิธีเตรียมข้อมูลและสูตรคำนวณใน Career Atlas Notebook ฉบับล่าสุด โดยใช้ธีม Admin Dashboard แบบแถบเมนูด้านซ้าย แถบด้านบน การ์ดสรุปสีพาสเทล และพื้นที่กราฟพื้นขาว อ้างอิงภาพตัวอย่างที่ผู้ใช้ส่งมา

## สิ่งที่มีในเว็บไซต์

- Career Ranking — เลือกประเทศและปี แสดง 10 กลุ่มอาชีพที่มีสัดส่วนสูงสุด
- Country Fingerprint — Heatmap ค่าเฉลี่ยสัดส่วน 4 ประเทศในช่วงปีร่วมกัน
- Career Evolution — เลือกกลุ่มอาชีพ เปรียบเทียบ 4 ประเทศ พร้อมข้อมูลจริง เส้นแนวโน้ม และการต่อแนวโน้ม 3 ปี
- Gender Gap — ประเทศไทย เปรียบเทียบค่าเฉลี่ยสัดส่วนอาชีพภายในผู้มีงานทำหญิงและชาย
- Thailand Deep Dive — เลือกจาก 43 กลุ่มอาชีพที่ประเทศไทยรายงาน พร้อมตาราง Actual Data และ Linear Trend
- Backtest — ผลการเปรียบเทียบ Trend Line กับ Naive จากปีทดสอบ 2024–2025
- ข้อมูลและวิธีใช้ — ที่มา นิยาม และข้อจำกัดของ snapshot

เว็บไซต์ไม่ใช้ Python Runtime, Google Colab, ipywidgets, บัญชี Google หรือบัญชี GitHub ของนักเรียน เมนูด้านซ้ายยุบ/ขยายได้บนคอมพิวเตอร์ และเปลี่ยนเป็นเมนูแบบเปิดทับหน้าจอบนอุปกรณ์จอเล็ก ข้อมูลสถิติถูกเตรียมไว้ในไฟล์ JSON และกราฟทำงานในเบราว์เซอร์

## ธีมและการใช้งานหน้าเว็บ

- แถบด้านบนสีเทาเข้ม แสดงชื่อ Career Atlas และสถานะไม่ต้อง Login
- แถบเมนูแนวนอนด้านบนแยก Dashboard, กราฟหลัก, การวิเคราะห์ประเทศไทย และข้อมูลวิธีใช้
- การ์ดสรุปข้อมูล 4 ใบใช้สีพาสเทล Coral, Blue, Yellow และ Green
- พื้นที่เนื้อหาและกราฟใช้พื้นขาว/เทาอ่อน พร้อมเส้นขอบบางและเงาอ่อน
- เมนูแนวนอนเลื่อนดูได้บนจอเล็ก เพื่อให้มีพื้นที่แสดงกราฟมากขึ้น

## ทดลองเปิดในเครื่องก่อนเผยแพร่

อย่าดับเบิลคลิก `index.html` โดยตรง เพราะเบราว์เซอร์บางตัวจะไม่อนุญาตให้หน้าเว็บอ่านไฟล์ JSON ในโฟลเดอร์เดียวกัน ให้เปิดเว็บเซิร์ฟเวอร์เฉพาะเครื่องแทน:

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `career_atlas_web` ใน VS Code
3. เปิด Terminal แล้วรันคำสั่งใดคำสั่งหนึ่ง:

```powershell
py -m http.server 8000
```

หรือ

```powershell
python -m http.server 8000
```

4. เปิด Chrome ไปที่ `http://localhost:8000`
5. ปิดเซิร์ฟเวอร์ด้วย `Ctrl + C` เมื่อทดสอบเสร็จ

## เผยแพร่ให้ห้องคอมเข้าใช้งานผ่าน URL

วิธีหนึ่งคือ GitHub Pages (เว็บไซต์จะเป็นสาธารณะ):

1. สร้าง Repository ใหม่บน GitHub เช่น `career-atlas-web`
2. แตก ZIP แล้วอัปโหลด **เนื้อหาภายในโฟลเดอร์** ขึ้น Repository โดยให้ `index.html` อยู่ที่ระดับราก (root)
3. เปิดแท็บ **Settings → Pages**
4. ในส่วน Build and deployment เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/(root)` แล้วกด Save
6. เมื่อ GitHub Pages เผยแพร่สำเร็จ จะมี URL รูปแบบ `https://ชื่อผู้ใช้.github.io/career-atlas-web/`
7. เปิด URL จริงทดสอบบนคอมพิวเตอร์ที่ไม่ได้ Login ก่อนนำไปเขียนบนกระดาน

ชื่อ URL ข้างต้นเป็นเพียงรูปแบบตัวอย่าง ไม่ใช่ URL ที่เผยแพร่แล้วในขณะนี้

## ขอบเขตข้อมูลที่ฝังไว้

- Snapshot ต้นทาง: 9,681 แถว / 20 คอลัมน์
- พบ `obs_value` ที่หายไป 11 รายการ (ไม่ตีความเป็นศูนย์)
- ชุดเปรียบเทียบ: 4 ประเทศ, 2013–2023, 21 กลุ่มอาชีพ, 2,772 แถว
- ประเทศไทยแบบเจาะลึก: 43 กลุ่มอาชีพ, 2013–2025, 532 แถว
- ตัวหารของสัดส่วน: จำนวนผู้มีงานทำรวมของประเทศในปีและเพศเดียวกัน (`employment_total`) จากแถว Total ของ ILOSTAT
- Backtest: ฝึก 2013–2023 และทดสอบปี 2024–2025

การเปรียบเทียบข้ามประเทศไม่ครอบคลุมทุกกลุ่มอาชีพที่แต่ละประเทศรายงาน ส่วน Thailand Deep Dive ใช้ชุดข้อมูลประเทศไทยโดยเฉพาะ จึงไม่ควรนำกลุ่มที่ไม่มีข้อมูลร่วมไปเทียบตรง ๆ กับประเทศอื่น

## ความเป็นส่วนตัว

เว็บไซต์นี้เป็น Static ไม่มีระบบ Login, ไม่มีแบบฟอร์มเก็บข้อมูล และไม่มีการบันทึกข้อมูลส่วนบุคคลของนักเรียน ข้อมูลสถิติที่ฝังในเว็บไซต์เป็นข้อมูลรวมระดับประเทศ/ปี/เพศ/กลุ่มอาชีพ ไม่ใช่ข้อมูลรายบุคคล

หากเผยแพร่ผ่าน GitHub Pages เว็บไซต์และไฟล์ข้อมูลจะเข้าถึงได้สาธารณะ จึงไม่ควรใส่ข้อมูลส่วนบุคคล รหัสผ่าน หรือข้อมูลภายในโรงเรียนที่ไม่ต้องการเปิดเผย

## การอัปเดตข้อมูลสดจาก ILOSTAT

เว็บไซต์ยังคงเป็น Static Dashboard และใช้ไฟล์ `data/career_atlas_data.json` เป็นแหล่งข้อมูลสำหรับกราฟทั้งหมด แต่ไฟล์ Snapshot สามารถสร้างใหม่จาก ILOSTAT API ได้โดยอัตโนมัติ

- สคริปต์ประมวลผล: `scripts/update_career_atlas.py`
- Workflow: `.github/workflows/update-data.yml`
- รอบอัตโนมัติ: ทุกวันจันทร์ 09:00 น. เวลาไทย (02:00 UTC)
- สั่งอัปเดตเอง: GitHub → Actions → Update Career Atlas data → Run workflow
- ปุ่มบนเว็บไซต์: โหลด Snapshot ล่าสุดที่เผยแพร่แล้ว ไม่เรียก API เพื่อเขียนข้อมูลลง Repository โดยตรง
- วันที่ดึงข้อมูลจะแสดงบน Dashboard และหน้า Data & Method

Pipeline ยึดกติกาจาก Notebook `Datahub_2026_live.ipynb`: ใช้ Indicator เดิม, ประเทศเป้าหมาย 4 ประเทศ, เพศ Total/Male/Female, ปีร่วมกัน, กลุ่มอาชีพที่มีข้อมูลครบ และตัวหาร `employment_total` เดิม หากประเทศหรือข้อมูลที่จำเป็นขาดหาย ระบบจะหยุดโดยไม่เขียนทับ Snapshot ที่ใช้งานอยู่

เมื่อข้อมูล ILOSTAT ไม่เปลี่ยน ระบบจะไม่สร้าง commit ใหม่โดยไม่จำเป็น
