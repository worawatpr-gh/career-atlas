# Career Atlas Thailand

แดชบอร์ดข้อมูลอาชีพประเทศไทยที่อัปเดตตามรอบการเผยแพร่ของ ILOSTAT

## ขอบเขตและกราฟ
- ประเทศไทยเท่านั้น ใช้ข้อมูล ILOSTAT ชุด `EMP_TEMP_SEX_OC2_NB_A`
- Career Ranking: 5 กลุ่มอาชีพที่มีสัดส่วนสูงสุด เลือกปีได้
- Career Evolution: ข้อมูลจริง, Linear Regression และการต่อแนวโน้ม 3 ปี (ไม่ใช่คำพยากรณ์ที่รับประกัน)
- Career Heatmap: ปี × กลุ่มอาชีพ แสดงสัดส่วนด้วยสีและตัวเลขทศนิยมหนึ่งตำแหน่ง
- Gender Gap: เปรียบเทียบสัดส่วนภายในผู้มีงานทำหญิงและชาย โดยใช้ตัวหารแยกตามเพศ
- Backtest: Linear Trend เทียบ Naive โดยฝึกถึงปี 2023 และทดสอบปีถัดไปที่มีข้อมูล

## การอัปเดตข้อมูล
เว็บไซต์เป็น Static Dashboard และใช้ `data/career_atlas_data.json` เป็น Snapshot ไม่ได้เรียก API สดทุกครั้งที่เปิดหน้าเว็บ

- สคริปต์ดึงข้อมูล: `scripts/update_career_atlas.py`
- Workflow: `.github/workflows/update-data.yml`
- รอบอัตโนมัติ: ทุกวันจันทร์ 09:00 น. เวลาไทย (02:00 UTC)
- อัปเดตเอง: GitHub → Actions → Update Career Atlas data → Run workflow
- ปุ่มบนเว็บไซต์โหลด Snapshot ล่าสุดที่เผยแพร่แล้ว ไม่ได้สั่งเขียนข้อมูลกลับ Repository

## นิยามและข้อควรระวัง
- สัดส่วนอาชีพ (%) = จำนวนแรงงานในกลุ่มอาชีพ ÷ จำนวนผู้มีงานทำรวมของประเทศไทยในปีและเพศเดียวกัน × 100
- จำนวนแรงงานมีหน่วยพันคน; ตัวหารมาจากแถว Total ของ ILOSTAT
- Missing values ไม่ใช่ศูนย์และไม่ถูกแทนด้วย 0
- Sex: Total เป็นยอดรวม ไม่ให้นำไปบวกซ้ำกับ Male และ Female
- กลุ่มอาชีพและปีที่แสดงขึ้นกับข้อมูลที่ ILOSTAT เผยแพร่
- ข้อมูลไม่ใช่เงินเดือน ความพึงพอใจ ตำแหน่งงานว่าง หรือความต้องการแรงงานอนาคต

เว็บไซต์ไม่มีระบบ Login หรือเก็บข้อมูลส่วนบุคคลของนักเรียน
